# Тест-план: Видимость блоков профиля

**Дата:** 18.03.2026
**Тестировщик:**
**Версия:** 1.0

---

## 🔧 НАСТРОЙКИ ВИДИМОСТИ

Для каждого блока можно выбрать один из трёх режимов:

- 🔓 **Публично** — видят все пользователи (авторизованные и нет)
- 👥 **Только друзьям** — видят только пользователи в списке друзей
- 🔒 **Скрыто** — видит только сам пользователь

---

| B2  | Контактная информация | Email, телефон                   |

| B4  | Достижения            | Награды, шевроны, знаки отличия  |
| B5  | Курсы                 | Список пройденных курсов         |

| B7  | Индекс Воеводы        | Рейтинг, статистика              |
| B8  | Команда               | Список коллег/подчинённых        |
